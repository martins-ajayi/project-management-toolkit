# UAT and quality plan

Establish entry, coverage, severity, evidence and acceptance rules.

**Reusable illustrative template.** Bracketed fields are completed for a real project; this is not an employer record.

| Area | Complete with |
| --- | --- |
| Entry | Stable build, reviewed cases, test environment and safe data |
| Coverage | Requirements, priority journeys, negative and boundary tests |
| Execution | Participants, planned suite, results and version |
| Severity | Definitions, triage authority, fix and retest responsibility |
| Exit | Full planned-suite pass denominator, Must coverage and critical-defect rule |
| Approval | QA recommendation and Business Owner acceptance |

Pass rate = passed / planned. Failed, blocked and unexecuted cases remain in the denominator. Define any different denominator explicitly. Representative sample rows do not constitute a full test suite. Retest corrected paths and affected regression scope.
